# Full Stack JavaScript pathway

Projects in this folder were completed as part of the Full Stack JavaScript
pathway of [The Odin Project](https://www.theodinproject.com/). Building on the
Foundations course, these projects move beyond static pages into intermediate
HTML and CSS, asynchronous JavaScript and APIs, automated testing, and core
data structures and algorithms.

## Skills practised

- Intermediate HTML and CSS: forms, responsive layouts, Grid, and Flexbox
- Consuming external APIs with asynchronous JavaScript (`fetch`, promises, `async`/`await`)
- Test-driven development with Jest
- Implementing and reasoning about common data structures and algorithms
- Building projects with a module bundler (webpack)

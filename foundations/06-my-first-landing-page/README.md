# My First Landing Page

A static landing page built as part of
[The Odin Project](https://www.theodinproject.com/) Foundations course,
recreating the course's target design from scratch.

## Overview

A single-page marketing layout with a header/nav bar, a hero section, a team
card grid, a featured quote, and a call-to-action banner. It's themed (loosely)
around *Angel Investigations* for a bit of fun while following the assignment's
structure.

## Features

- Fixed-structure header with a logo and navigation links
- Hero section pairing headline copy with a call-to-action and image
- Responsive card grid for the team section
- Quote block and call-to-action banner
- Web font loaded from Google Fonts (Roboto)

## Skills Practiced

- Flexbox for layout across the header, hero, and card grid
- Recreating a supplied design from a reference image
- Semantic structure and consistent class naming
- Loading and applying an external web font

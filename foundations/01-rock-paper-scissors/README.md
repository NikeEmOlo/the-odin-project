# Rock, Paper, Scissors

A browser-based Rock, Paper, Scissors game built as part of
[The Odin Project](https://www.theodinproject.com/) Foundations course.

## Overview

Play a best-of-five match against the computer. The game moves through three
screens — a start screen, a choice screen, and a results screen — showing each
side's pick, a running score, and the overall winner once five rounds are up.

## Features

- Best-of-five match with round-by-round scoring
- Computer opponent that picks at random each round
- Screen-based flow (start → choose → results) driven by showing/hiding sections
- Illustrated hand choices with per-round result images
- Replay from the final screen to start a fresh match

## Skills Practiced

- Managing game state in a plain object (scores, round count)
- DOM manipulation and event handling for button-driven choices
- Conditional logic to resolve the winner of each round
- Structuring a multi-"screen" single-page app by toggling visibility

## Running It

Open `index.html` in a web browser (or serve it with something like VSCode's
Live Server extension).

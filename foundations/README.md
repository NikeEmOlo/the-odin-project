# Foundations course

Projects in this folder were completed as part of the Foundations section of
[The Odin Project](https://www.theodinproject.com/). They focus on developing the
fundamental HTML, CSS, and JavaScript skills needed to build basic, static
websites and to prepare for the more advanced sections of the course.

## Skills practised

- Foundational HTML and CSS for structuring and styling static pages
- Foundational JavaScript, including DOM manipulation and event handling
- Organising code with functions, the module pattern, and closures
- Using the command line, Git, and GitHub to track work

## Projects

| Project | Description |
| --- | --- |
| [01 – Rock Paper Scissors](./01-rock-paper-scissors/) | A browser-based game of Rock, Paper, Scissors. |
| [02 – Noughts and Crosses](./02-naughts-and-crosses/) | A two-player tic-tac-toe game that tracks scores and highlights the winning line, built with the module pattern. |
| [03 – Calculator](./03-calculator/) | The capstone Foundations project: a working calculator supporting the four basic operations and additional features. |
| [04 – Etch a Sketch](./04-etch-a-sketch/) | A sketchpad that lets the user draw on an adjustable grid, pick colours, and clear the canvas. |
| [06 – My First Landing Page](./06-my-first-landing-page/) | A static landing page recreated from a supplied design, practising layout with Flexbox. |
| [07 – Using Web Fonts](./07-using-web-fonts/) | A short exercise in loading and applying custom web fonts. |
| [08 – First Web Page (Odin Recipes)](./08-first-web-page/) | The first HTML project: a recipes website built from scratch using links, lists, and images. |
